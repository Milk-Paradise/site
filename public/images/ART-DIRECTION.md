# Milkshake Studio — original hero artwork

Generated with the built-in ImageGen tool for this project. No images, logos, client work or protected artwork were taken from the reference websites. The visual references informed scale, spacing and art direction only.

## Project files

- `pop-sculpture.webp` — 121 KB, warm editorial sculpture.
- `pop-sculpture-mobile.webp` — 46 KB, smaller responsive asset.
- `dark-sculpture.webp` — 112 KB, cobalt sculptural environment.
- `dark-sculpture-mobile.webp` — 43 KB, smaller responsive asset.

The original generated PNGs remain in Codex's generated_images folder. Project assets are encoded into WebP by `scripts/prepare-hero-assets.cjs`. Only the active theme's CSS background is requested; mobile screens use the smaller files. These are static images, not a continuous WebGL or video scene.
