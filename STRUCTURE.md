# Как устроен Milkshake Studio

Сайт — один лендинг с переключаемыми светлой и тёмной темами, ценами, FAQ и общей формой заявки. Адрес `/privacy` содержит черновик политики обработки данных, `/api/health` проверяет доступность приложения.

Ключевые файлы: `src/app/page.tsx` — разделы, `src/app/privacy/page.tsx` — политика, `src/components/lead-form.tsx` — форма, `src/app/api/leads/route.ts` — её серверный обработчик, `src/lib/delivery.ts` — отправка в Telegram, `src/lib/lead-schema.ts` — проверка полей. Цены находятся в `src/config/pricing.ts`, тексты FAQ — в `src/config/content.ts`. Стили светлой и тёмной тем — `src/styles/pop.css` и `src/styles/dark.css`.

Путь заявки: заполнение формы → подтверждение согласия → сервер проверяет настройки, Origin, размер и содержимое запроса → Telegram Bot API доставляет заявку в указанный чат. Реальная отправка остаётся выключенной, пока `PRIVACY_READY=false`. По решению владельца CAPTCHA и Redis не используются; ограничение частоты и надёжное предотвращение дублей не реализованы.

Настройки запуска и незавершённые вопросы перечислены в `LAUNCH-READINESS.md`. Иллюстрация админки на сайте не является работающей панелью управления.
