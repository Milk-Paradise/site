# Milkshake Pop — согласование направления

Первый экран и начало следующей секции. Это статический дизайн-прототип, а не готовый сайт и не работающая форма. After Dark будет следующим этапом после согласования Pop. Публичных контактов и секретов нет.

Открыть `index.html` или запустить из этой папки `node serve.cjs`, затем открыть http://127.0.0.1:4173.

После согласования перенести дизайн в основной проект Next.js. Текущие цены в прототипе иллюстративно зафиксированы по ТЗ; в основном проекте будет единая конфигурация цен.
